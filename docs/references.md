# References and prior art

These are starting points for engineering study, not proof that BWR-1 meets any standard.

## WMO / ISO

- WMO, Weather Radar Observations / ISO-WMO common standard on radar:
  https://community.wmo.int/site/knowledge-hub/programmes-and-initiatives/weather-radar-observations/iso-wmo-common-standard-radar
- WMO-No. 1257, Guide to Operational Weather Radar Best Practices:
  https://community.wmo.int/site/knowledge-hub/programmes-and-initiatives/weather-radar-observations/guide-operational-weather-radar-best-practices-wmo-no-1257

## FMCW weather radar

- Middle East Technical University, *Design of an experimental FMCW weather radar*:
  https://open.metu.edu.tr/handle/11511/24919

The work is useful prior art for low-power X-band FMCW meteorological measurements. BWR-1 parameters must still be derived independently.

## Open FMCW hardware / maker references

- SimpleFMCWRadar:
  https://github.com/lukeweston/SimpleFMCWRadar
- matthuszagh/fmcw:
  https://github.com/matthuszagh/fmcw
- ckflight/FMCW-RADAR:
  https://github.com/ckflight/FMCW-RADAR

These projects are references for RF/DSP implementation patterns; they are not drop-in meteorological-radar designs.

## Documentation rule

When a published design influences a BWR-1 engineering choice, record:
1. the source;
2. the parameter/idea borrowed;
3. why it applies;
4. what was independently calculated or measured.
