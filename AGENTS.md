# Agent instructions

Read `~/vibecoding/AGENTS.md` first: it holds the workspace-wide rules (English-only repositories, safety, git/PR policy) that apply to this project. This file adds to them and wins on conflicts.

See `README.md` and `docs/` for the project specification.

## Repository visibility

This repository is **public**: everything committed, including history, is world-readable. Never commit credentials, personal data, the exact location of the property or station, private measurements, or content copied from private projects. If something sensitive was committed, tell the owner; do not just delete it in a later commit.
